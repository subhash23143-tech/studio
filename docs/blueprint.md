# **App Name**: VerdantFlow

## Core Features:

- Task Input: Allow users to add tasks with deadlines and descriptions.
- Task Prioritization: Enable users to prioritize tasks using a drag-and-drop interface.
- Task Completion: Enable marking tasks as complete.
- Daily View: Display tasks in a clean, organized daily schedule.

## Style Guidelines:

- Primary color: Soft green (#A7D99D) for a calm and productive feel.
- Background color: Off-white (#F5F5F5) to provide a clean, unobtrusive backdrop.
- Accent color: Forest green (#558B2F) for focus and highlighting.
- Body and headline font: 'PT Sans', a humanist sans-serif font, to offer a blend of modern style and readability.
- Use simple, minimalist icons for task categories and actions.
- Maintain a clean, uncluttered layout for easy task management and daily scheduling.
- Use subtle animations for task completion and reordering to enhance user experience.
